# South Asia Nighttime Lights Animation

A Google Earth Engine visualization of nighttime lights across South Asia from 2010 to 2025.

## Data

- DMSP-OLS nighttime lights: 2010–2013
- VIIRS DNB nighttime lights: 2014–2025

## Region

South Asia, approximately 60°E–100°E and 5°N–38°N.

## Visualization

The animation shows changes in nighttime light intensity over time, with the year displayed in the upper-right corner and a radiance legend in the lower-left.

## Tools

- Google Earth Engine
- JavaScript
- DMSP-OLS
- VIIRS DNB

## Output

The resulting animation can be viewed in the `outputs/` folder.
